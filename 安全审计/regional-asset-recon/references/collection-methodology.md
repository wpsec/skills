# 搜集方法与判定规则

## 来源优先级

1. 官方来源：政府门户及部门目录、国资监管机构、事业单位/学校/医院官网、政府采购和公开文件。用于单位名称、上下级关系和官方域名归属。
2. 被动资产索引：FOFA、Shodan。用于已索引的主机、端口、服务、标题、ICP、证书和地理字段。
3. 公共证书透明度与公开 DNS 数据：用于发现证书域名、子域名和历史关联。
4. 搜索引擎、商业目录和新闻页面：只生成线索，需官方或独立证据确认后才能进入主表。

每个单位来源记录页面标题、完整 URL、采集日期和支持的具体事实。资产来源记录平台、查询线索、检索日期和返回记录。区分本次采集时间与平台最后观测时间。

## 演练范围门槛

- 仅有区域名时，工作限于官方单位目录、单位上下级关系和用户本地材料归档。不得把区域内所有主体默认当作已授权目标。
- 调用资产索引前，记录可追溯的授权依据，并从任务方给定范围整理“按单位整体外网资产纳入”的授权单位及逐个授权的 IP。API 查询计划中的每条单位线索必须指向该清单中的单位；Shodan 单 IP 查询必须命中授权 IP 清单。若授权文件只列单个域名或网段，不能据此改做整个单位的名称搜索；本版计划无法表达的范围不执行平台查询，并在覆盖说明中注明。
- 供应商单独记录授权状态、授权实体和资产标识。只有明确纳入授权范围的供应商才可查询和列入主表；采购/运维关系本身不能扩大授权边界。
- 未确认授权、超出清单或仅因同网段/共享托管关联发现的记录，不作为扩展查询种子；保留为待核线索或排除并在覆盖说明中计数。
- 报告生成时再次校验授权依据和授权单位。授权材料缺失或单位不在清单中的记录不得进入主表，即便资产数据中自称 `scope_status=in_scope`。

## 单位与业务线索

建立规范名、简称、旧名、英文名、拼音、上级单位、行政区和官方来源映射。按单位职责检索其业务平台类别，例如市场监管、住建、医保、教育、交通、公共资源交易和政务服务。业务名称只用于产生搜索词；未出现可核验的单位关系时放入待核源线索。

供应商资产必须有直接的采购/运维/官方合作说明或明确的域名、页面、证书关系，且本次演练范围明确纳入供应商。共享云、CDN、托管商和供应商关联别名不能证明其全部资产属于目标范围。

## 关联证据分级

- 高：官方页面直接公布域名/系统；ICP 主体与目标单位精确匹配且域名一致；官方材料明确列出系统主机；多个独立来源对同一关系相互印证。
- 中：FOFA/Shodan 的证书、页面主办方、标题、备案和目标单位名称组合吻合，但无官方直接映射。进入候选或复核后再决定是否纳入主表。
- 低：仅名称相似、证书 O/CN/SAN 单字段、共享 IP/CDN、相同 ASN、相同 C/B 网段、IP 属地或同供应商。只进入候选附表。
- 证书序列号/指纹、Subject O/CN、SAN、通配符或自签名证书可用于扩展搜索；证书关联本身不是单位所有权证明。
- 共享 IP 上多个域名分别保留；不得把共享托管中的所有站点归给目标单位。

主表只接收明确关联、范围内的资产。范围外或无法判断的供应商和第三方主机留在候选表，并记录“范围待确认”。

## 分维度检索

### 域名

从官方域名和本地种子出发，查子域名、同 ICP 主体域名、证书关联域名、公开 DNS/证书透明度记录及 CNAME。常规 DNS 只解析已发现域名；泛解析判断只用有限的随机标签 DNS 查询，不发起 HTTP 请求、不做字典爆破。

### FOFA

使用账户可用且不消耗 F 币的查询能力。检索种子域名、ICP备案主体、单位名称变体、页面标题/正文、证书序列号/指纹、证书 Subject O/CN、证书域名/SAN、已知 IP 和服务字段。仅请求报告需要的字段，避免收集无关正文。

FOFA 运行限制：最多 10,000 次 API 请求、最多 100,000 条结果；每条查询最多 20 页；单次请求超时 20 秒；网络错误或 HTTP 5xx 最多重试 2 次。重试间隔递增。遇到 HTTP 429、额度耗尽或错误码 820041 时立即停止 FOFA，不重试。响应中的 consumed_fpoint 非零时立即停止后续查询并记录实际返回值。额度限制下保留部分结果，覆盖表列出已完成/未完成线索。

### Shodan

调用前读取 api-info 的账户状态。对已知全球可路由 IP 使用 host lookup 获取已有服务索引；按目标单位/域名/证书线索做搜索。带过滤器的搜索或翻页前检查可用 query credits；额度不足时跳过需要消耗额度的请求。每次运行最多 2,500 次 API 请求，每条搜索最多 20 页，超时 20 秒，网络错误或 5xx 最多重试 2 次。不得购买或使用 scan credits，不调用按需扫描接口。记录请求前后额度和未完成线索。

### IP 与网段

记录平台已索引的 IP、端口、协议、服务/产品/版本、标题、IP 属地和观测时间。对已知域名做普通 A/AAAA 解析。相邻 C/B 段只通过被动索引形成网段候选，不展开 CIDR、不扫描。仅同网段或同 ASN 的记录不得进入主表。

## 去重

- 证据记录与资产实体分开去重。
- 域名服务键：标准化 FQDN + 已知端口 + 协议；无端口时保留 FQDN，不推测默认端口。
- IP 服务键：规范化 IP + 已知端口 + 协议；无端口时保留 IP。
- 不同 FQDN 指向同一 IP:端口时分别保留域名记录并关联到共同 IP；一个域名指向多个 IP 时保留所有解析关系。
- “单位名称 + 来源”只能合并重复证据，不能作为资产实体去重键。
- 合并重复记录时并集合并来源和关系依据，不覆盖冲突字段；冲突值保留在备注/候选证据，待复核。

## 重点标注

重点标记必须同时满足：

1. 单位关联状态为 confirmed，且关联依据可追溯；
2. IP 属地由 FOFA/Shodan 或可靠 IP 地理数据明确匹配目标区域；单位地址、备案地、Whois 注册地不能替代 IP 属地；
3. 标题命中固定关键词：系统、业务系统、平台、监管平台、管理系统、管理后台、申报系统、业务办理、公共服务平台、交易平台、信息平台、数据平台。

普通官网、新闻页和门户首页不标重点。关键词的语义近似只由模型提出候选，必须落到可复核标题/词表匹配；IP 属地缺失或不匹配时保留资产但不标重点。重点是复核优先级，不代表存在漏洞或可利用。

## API 安全与恢复

- 凭据只从约定的本地文件读取；HTTP 客户端不记录完整 URL，避免密钥出现在 query string 日志或异常中。
- 状态文件只保存 query 摘要/哈希、游标、已完成索引、调用计数和错误类型，不保存凭据。
- 仅对超时、连接错误和 5xx 重试；不重试认证错误、429、平台额度错误、F 币消费错误或无效查询。
- 中断后按状态游标继续；已完成线索不重发。状态文件和原始 JSONL 放在临时目录，最终 Excel 不含密钥。
